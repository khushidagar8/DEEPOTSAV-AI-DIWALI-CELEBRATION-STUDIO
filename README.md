# 🪔 DEEPOTSAV AI – Diwali Celebration Studio

**DEEPOTSAV AI** is an interactive Python-based Diwali Celebration Studio designed to make festival celebrations more creative and enjoyable.

It provides multiple festival-themed features through a professional graphical user interface built using Python Tkinter.

## ✨ Features

- 🏠 **Dashboard:** Welcome screen with festival-themed design.
- 💌 **Wish Generator:** Generate personalized Diwali wishes for family, friends, teachers, and professionals.
- 🎨 **Greeting Card Studio:** Create and save customized Diwali greeting messages.
- 🧠 **Diwali Quiz:** Test your knowledge about Diwali with an interactive quiz.
- 🌸 **Rangoli Gallery:** Explore colorful, randomly generated rangoli patterns.
- ⏳ **Festival Countdown:** Calculate the countdown to a selected festival date.
- 🌙 **Professional GUI:** Attractive dark-purple and golden theme.

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Random Module
- Datetime Module
- OS Module

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project file in Python IDLE.
3. Open `DEEPOTSAV_AI.py`.
4. Press **F5** to run the application.
